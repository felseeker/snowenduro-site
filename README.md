# Snowenduro — сайт зимней техники

Домен: `snowenduro.ru`.

Исходные макеты Google Stitch распакованы в `stitch-export/`. Этот каталог хранит оригинальный экспорт и служит визуальной и контентной опорой для сайта.

## Экспорт Stitch

- 6 HTML-экранов: главная, Snowbike, каталог, доставка, о компании/контакты, карточка снегохода.
- 12 скриншотов: по одному скриншоту на каждый макет и шесть дополнительных референсных экранов.
- `arctic_technical_precision/DESIGN.md`: палитра, типографика, сетка, компоненты и состояния.
- Подробная опись экранов: `docs/stitch-audit.md`.

Макеты используют Tailwind CDN и удалённые изображения. В рабочем приложении визуальные решения переносятся в локальные компоненты и стили; содержимое экспорта сохраняется без изменений.
