# SnowEnduro

Сайт зимней техники для домена **snowenduro.ru**: Snowbike-комплекты для эндуро и снегоходы под заказ из Китая. Данные о моделях, характеристиках и ценах оставлены как заменяемые placeholders до подтверждения поставщиком.

## Запуск

Требуется Node.js 20.9 или новее.

```powershell
npm install
npm run dev
```

Откройте `http://localhost:3000`. Для production-сборки выполните `npm run build`, затем `npm start`. `npm run lint` проверяет код ESLint.

## Настройка перед публикацией

1. Скопируйте `.env.example` в `.env.local`.
2. Заполните `NEXT_PUBLIC_TELEGRAM_URL`, `NEXT_PUBLIC_PHONE` и `NEXT_PUBLIC_CONTACT_EMAIL` реальными контактами.
3. Обновите каталог и карточки в `data/products.ts`: названия моделей, характеристики, цены, комплектацию и ссылки на подтверждённые фотографии.
4. Обновите регион и деловые сведения в `data/site.ts`.
5. Подключите обработчик формы в `components/LeadForm.tsx` и настройте согласие/хранение данных. Сейчас форма валидирует поля в браузере, но ничего не отправляет.
6. Проверьте и адаптируйте проект политики конфиденциальности в `app/privacy/page.tsx` с учётом реального оператора, цели обработки и выбранного сервиса заявок.
7. Замените общие медиа на актуальные материалы поставщика по выбранной модели. Источники текущих фото и видео указаны в `MEDIA_SOURCES.md`; AI-визуалы для Snowbike раскрываются одной короткой строкой внизу сайта.

Не публикуйте неподтверждённые характеристики и сроки как факты. Текущие значения `Уточняется`, `После подтверждения поставщика` и `Цена по запросу` — намеренные placeholders.

## Страницы

- `/` — главная, зимнее видео, два направления, scroll-story Snowbike, подборка, процесс и маршрут.
- `/snowbike` — устройство комплекта, этапы подбора, проверка совместимости, сценарии и FAQ.
- `/catalog` — категории снегоходов, фильтрация, поиск и сравнение направлений.
- `/catalog/[slug]` — страница направления с галереей, статусами данных и заявкой.
- `/delivery` — маршрут поставки, этапы заказа, условия и FAQ.
- `/about` — модель работы, контакты и запрос.
- `/privacy` — проект политики конфиденциальности и описание демо-формы.

## Структура

- `app/` — маршруты Next.js App Router, глобальная тема, metadata, sitemap и robots.
- `components/` — навигация, формы, каталог, галереи и интерактивные блоки.
- `data/` — редактируемые сведения сайта и категории товаров.
- `public/media/` — локальные изображения и фоновое видео.
- `MEDIA_SOURCES.md` — исходные страницы медиа и заметки об использовании.
- `stitch-export/` — неизменённый Google Stitch экспорт; обзор экранов — `docs/stitch-audit.md`.

## Стек

Next.js App Router, React, TypeScript, CSS, Lucide. Стиль и адаптивная сетка реализованы локально; тяжёлую motion-библиотеку не добавляли. Учитывается `prefers-reduced-motion`, видео подгружается по близости к экрану, изображения используют `next/image`.
